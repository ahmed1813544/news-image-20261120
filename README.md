# The World in One Day — Friday 20 November 2026

An entry for make.fun's bounty **"Sum up 20 November's world news in one image"** (news-image-20261120).

The entry is a single front-page image summing up the world's news of Friday 20 November 2026: the Kyiv bridge barrage, Cyclone Akvan's landfall in India, the AI sell-off in Asia's markets, the UK–EU reset deal, COP31's deadlock, and dozens more of the day's stories across every region.

## How it runs

`main.py` copies the picture stored in this repository (`entry.png`) to `/output/entry.png`, byte for byte. It uses only the Python standard library, needs no network, and writes identical bytes on every run.

The drawing scripts (`draw.py`, `draw2.py`) record an earlier code-drawn version of the page, built and checked in the same session.
